# 숨잇 (SOOMIT) | AI 기반 폐암 진료 의사결정 지원 시스템

> 검사 결과와 AI 분석 정보를 연결해 의료진의 폐암 진료 의사결정을 지원하는 팀 프로젝트입니다.

[원본 팀 저장소](https://github.com/0JustDoIT1/LUNG-CDSS-MOBILE) · [프로젝트 포트폴리오](https://app.notion.com/p/f7e95eaad1228319a216819953ab8cbf)

## 프로젝트 소개

폐암 진료는 흉부 X-ray, CT, PET-CT, 조직·유전자 검사, PD-L1 결과, 치료계획과 처방까지 여러 검사와 부서의 업무가 연결됩니다.  
숨잇은 검사 결과, AI 분석 후보, 진료 단계와 검사 오더 상태를 함께 보여주어 의료진이 다음 업무를 확인하고 처리할 수 있도록 설계했습니다.

```text
X-ray → CT → PET-CT·TNM → 조직·유전자 → PD-L1 → 치료계획 → 처방
```

AI 결과는 의료진의 판단을 지원하는 후보와 근거로 제공하며, 최종 확정은 의료진 검토를 거치도록 구성했습니다.

## 주요 기능

- 역할 기반 서비스: 호흡기내과, 영상의학과, 병리과, 환자
- 영상·병리 결과 조회 및 의료진 검토 흐름
- CT 기반 종양 분할과 TNM 병기 후보 분석
- 검사 오더, 단계별 저장·확정, 치료계획·처방 연계
- JWT 인증과 담당 부서·담당자 검증

## 개인 기여

이 저장소는 팀 프로젝트의 포트폴리오용 포크입니다. 아래 내용은 제가 작업한 기록을 기준으로 정리했으며, 팀 전체 작업과 개인 기여를 구분해 기술합니다.

- **CT 종양 분할 성능 개선**
  - nnU-Net v2 기반 실험에서 50mm crop과 학습 기간 확장을 비교
  - Dataset503 Dice 0.4202 → Dataset504 best Dice 0.5124 기록
  - 250 epochs 실험: 학습 333명, 검증 84명

- **TNM 분석 및 진료 워크플로우**
  - T/N/M 모델 및 TNM9 병기 규칙 엔진 관련 작업
  - 호흡기내과 화면의 검사 결과 조회, 저장·확정 조건과 후속 처리 연결
  - 단계별 결과 상태와 버튼 노출 조건을 점검

- **오류 해결 및 회귀 검증**
  - CT 확정 이후 기존 활성 오더를 재사용하도록 처리해 중복 오더 오류 해결
  - CT 확정·오더 처리·진료 단계 변경을 트랜잭션으로 묶고 실패 시 롤백
  - 관련 회귀 테스트 32/32 통과 기록

## 성과

| 항목 | 결과 |
| --- | --- |
| CT 종양 분할 | Dice 0.4202 → best 0.5124 |
| 워크플로우 안정성 | CT 후속 처리 관련 회귀 테스트 32/32 통과 |
| 진료 흐름 | 검사 결과 검토부터 치료계획·처방까지 단계 연결 |

> Dice는 예측 종양 영역과 정답 영역의 겹침을 나타내는 지표입니다. 위 수치는 기존 실험 기록을 기준으로 하며, 최종 발표 자료와 원본 결과를 함께 확인합니다.
